# Backend

Django aplikacija z REST API-jem (poslovna pravila, prijava, dostop do podatkovne baze). Koda bo dodana v naslednjih fazah projekta.

Tehnologije: Python 3.12, Django 5, Django REST Framework, SQLite. Glej [04 – Arhitektura in tehnološki sklad](../docs/04-arhitektura-in-tehnoloski-sklad.md).
